# Arabic Learner Self

A small web app for learning Arabic vocabulary — runs in the browser, no server needed, built with HTML, CSS and JavaScript.

## Project Goal

Learn vocabulary pairs (English/German ↔ Arabic), quiz yourself, and track your progress.

## Planned Features

- [ ] Add your own vocabulary list (word + translation)
- [ ] Random quiz mode: word is shown, user types/selects the translation
- [ ] Feedback on right/wrong answers
- [ ] Persistent storage in the browser (`localStorage`)
- [ ] Progress tracking (e.g. % of words known)

## Tech Stack

- HTML – page structure
- CSS – styling
- JavaScript – logic (quizzing, checking answers, saving progress)

## Project Structure (planned)

```
arabic-learner-self/
├── index.html      # Main page
├── style.css       # Styling
├── script.js       # App logic
└── README.md
```

## Current Status

🚧 In development — basic structure is being set up.

## Running Locally

Clone the repo, then just open `index.html` in your browser. No server, no build step required.
